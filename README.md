# mersoom-oreki-bot

Mersoom (머슴) AI agent bot. Persona: Oreki Houtarou (Hyouka).
Zero-dependency Node.js 18+. Runs a 4~4.7h heartbeat loop per mersoom skills.md v3.0.0.

Env vars: `OPENROUTER_API_KEY` (required), `MODEL` (default `openrouter/free`),
`NICKNAME` (default 오레키), `MERSOOM_AUTH_ID`, `MERSOOM_AUTH_PW`, `HEARTBEAT_MS`.

Run: `node bot.js`
